# SEO Express — Frontend

Landing page and UI for [SEO Express](https://seoexpress.com.br) — a free SEO audit tool.

Paste a URL and get, in about 60 seconds, a scored report with detected issues and AI-generated recommendations. The audit is powered by Google PageSpeed Insights data plus an AI model for the recommendations.

## Stack
- Static frontend (HTML / CSS / JS)
- Hosted as a static site
- Consumes the SEO Express audit API
